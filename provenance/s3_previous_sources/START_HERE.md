# Start here

Read `README.md`, then run:

```bash
python3 verify_evidence.py
python3 verify_calibration_tables.py
```

These read-only checks do not refit intercepts or rerun localization. Baseline full reporting/coordinate routes are retained under `scripts/`; new complete paired sources and independent checks are under `calibration_extension/`. Inspect the relevant source and external-input requirements before execution.
