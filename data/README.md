# External source inputs

Raw LoRaWAN, message JSON, coordinate catalogue and Sigfox source measurements are not redistributed. The source record is DOI 10.5281/zenodo.3904158. LoRaWAN/JSON/catalogue exact payload hashes are in coordinate_provenance/EXTERNAL_INPUTS.json. The older EXTERNAL_INPUTS.json here names only the LoRaWAN CSV and catalogue, not the Sigfox hashes.

The original Sigfox header-normalization and coverage source is supplied in reproduction_sources/. The raw Sigfox files and original normalization receipts were not available for this revision's new checks. Source publisher checksums and the emitted population/curve comparisons must be checked on a fresh reproduction; no matching historical Sigfox byte hash is invented.
