# Scientific figure assets

Ten generated vector PDF figures are present. Regenerate tables with `python scripts/build_figure_tables.py` and PDFs with `python scripts/build_figures.py` after installing `requirements-figures.txt`. Review changes, then explicitly update checksums. Original raw logs and immutable author archives are preserved.

`FIGURE_MANIFEST.json` links each PDF to its numerical sources. `panels/` holds the independent chart PDFs used to compose multi-panel figures. No generative image system was used. These standalone figures still require inspection after compilation in the official journal template.
