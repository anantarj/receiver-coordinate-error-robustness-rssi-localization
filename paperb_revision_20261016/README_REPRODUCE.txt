PAPER B — 16 OCTOBER 2026 SCIENTIFIC REVISION

This additive package preserves the original finite estimators and predictions.
It adds complete candidate capture, targeted numerical audits, conservative
found-pool sensitivity, calibration validation, comparative consequences, and
finite mechanism/removal diagnostics. It is not a new independent campaign.

DIRECTORY LAYOUT

This package extracts into two sibling directories: paperb_revision_20261016/
and paperb_execution_20261015/. The preceding broader-validation package
retains its scientific files unchanged; submission PDFs and manuscript
sources are excluded from this public distribution. Keep both dated roots intact.
The older PAPERB_REPRODUCIBILITY_v1.2.0.zip remains a separate immutable archive
for the earlier simulations, WCL controls and historical records. Do not apply
its historical version checks to these new files.

Use Python 3.12 with NumPy 2.3.5 and SciPy 1.17.0 to reproduce the numerical
environment. Pandas, matplotlib and pyproj are used by analysis/figure/input
preparation scripts. Saved-output verification does not require optimization.

FIRST CHECK

Run python3 verify_package.py from the extracted revision root. This checks
the file manifest only; integrity is distinct from scientific correctness.
The retained scientific receipts document independent formula, mapping,
coverage and original-file checks. A COMPLETE receipt does not certify a
global optimum, unique location, physical coordinates or deployment accuracy.

SCIENTIFIC ROUTES (relative to the revision root)

Numerical recovery:
  python3 numerical/verify_recovery.py
  python3 numerical/verify_targeted_audits.py

Calibration:
  python3 calibration/src/verify_calibration.py
  python3 removal/verify_completed_calibration_public.py

Consequence reductions:
  python3 consequences/src/original_consequences.py
  python3 consequences/src/candidate_consequences.py
  python3 consequences/src/candidate_consequences.py --enhanced-directory numerical/targeted_audits

These reductions can refresh reporting files. Run them in a working copy,
then compare scientific values against the retained outputs. Do not regenerate
locks or expected fingerprints to make an unexplained mismatch disappear.
The recovered primary and targeted enhanced pools remain separate analyses.
All repeated exact numerical inputs share their candidate under each explicit
alternative rule. Reference-scored bounds are diagnostic assignments, not a
production estimator or a statistical confidence region.

Finite theory replay and relocation checks:
  python3 theory/run_finite_diagnostics_public.py --verify-only
Read theory/README_PORTABLE.txt before a fresh diagnostic replay. The portable
runner retains original protocol hashes and maps only the two known dated
archive prefixes to the current extraction root.

Original primary prediction reproduction is documented by the preceding
package. Candidate recovery uses numerical/recover_candidates.py run --workers N;
completed hash-verified checkpoints are reused. To perform a genuinely fresh
solver run, first make a separate working copy and move its candidate outputs
and run receipts outside that copy while retaining locked inputs/protocols.
Keep the pilot and regular recovery partitions distinct. No primary output is
silently replaced by an enhanced endpoint. Targeted audits stop after the
declared 30,000-split budget and at most one 100,000-split escalation.

The calibration query producer is calibration/src/run_extension_queries.py.
Its original fit/validation split and selected coefficients are locked before
query outcomes. Both frozen and refitted endpoints use fitting records only.
The query cohorts were used previously; they are not a newly acquired test set.
The all-roster residual companion uses the original third-party CSV; obtain it
from DOI 10.5281/zenodo.3904158 and verify SHA-256

Place it at sibling paperb_development_20261015/inputs/lorawan_antwerp_2019_dataset.csv

INTERPRETIVE BOUNDARIES

The main result is conditional comparison of calibration information regimes.
It is not correction of unknown receiver faults, proof of physical coordinate
truth, or universal improvement from recalibration. The same campaign supplies
both map configurations and all spatial folds. Computational state counts and
repeated directions are not independent sample sizes. Gross coordinate stress,
finite numerical tolerances, retained reference uncertainty and failure cases
remain visible in the scientific supplement and complete result registers.
