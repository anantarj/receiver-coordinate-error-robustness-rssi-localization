# Licensing

This repository uses a split licensing model:

- Author-created software/code: **MIT License** — see the top-level `LICENSE`.
- Author-created documentation and derived non-code data/artifacts: **Creative Commons Attribution 4.0 International (CC BY 4.0)** — see `CC-BY-4.0.txt`.
- Third-party source data and materials: retain their original terms and are not relicensed by this repository. See `THIRD_PARTY_NOTICES.md`.

When a file's status is ambiguous, do not assume the top-level MIT license overrides third-party or non-code terms.
